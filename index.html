Privacy Policy

Last updated: September 17, 2026

This Privacy Policy explains how TryAI Flow Automator ("the Extension") handles information when you use the Chrome extension.

1. What the Extension Does

TryAI Flow Automator is a Chrome extension designed specifically to help users automate image and video generation workflows in Google Flow.

The Extension provides features such as prompt management, prompt queues, image references, generated asset naming, and automation of actions within the Google Flow website.

2. Information the Extension Handles

The Extension may handle information that the user provides or selects while using Google Flow, including:

  • Text prompts entered by the user.
  • Image references selected or uploaded by the user.
  • Names or tags assigned to generated assets.
  • Automation settings and preferences.
  • Information contained in the Google Flow webpage that is necessary to perform the requested automation.

3. How Information Is Used

Information handled by the Extension is used only to provide the Extension's core functionality, including entering prompts, managing references, organizing prompt queues, and interacting with Google Flow at the user's request.

4. Data Storage

The Extension may use Chrome's local extension storage to save settings, prompt data, and automation preferences needed for the user's workflow.

The Extension does not operate a separate server or database for collecting users' prompts or generated content.

5. Data Sharing

We do not sell user data.

We do not transfer user data to third parties for advertising, creditworthiness, lending, or unrelated purposes.

The Extension interacts with Google Flow because this interaction is necessary to provide the Extension's requested automation functionality.

6. User Control

Users control the prompts, references, and other content they choose to provide to Google Flow through the Extension.

Users may stop using the Extension or remove it from Chrome at any time.

7. Security

We take reasonable measures to limit the handling of information to what is necessary for the Extension's functionality.

8. Changes to This Privacy Policy

This Privacy Policy may be updated from time to time. Any updated version will be published on this page with a revised "Last updated" date.

9. Contact

If you have questions about this Privacy Policy or TryAI Flow Automator, please contact the developer using the contact email associated with the Chrome Web Store developer account.
